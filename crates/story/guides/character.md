# 角色弧线

目标：梳理一个角色在主线中的登场、关系与变化，给出有出处的人物小传。

## 工作流
1. `zzz_character(name=…)`：拿到设定档案、按章节的出场/台词统计、首见场景、常同场角色。
   - 「匹配说话人」为空时，说明该角色在数据里没有可解析的说话人，只能依据被提及与设定资料。
   - 「相关名称」（如「零号·安比」之于「安比」）是不同的说话人条目，需要时单独查询。
2. 读设定档案（`zzz_read(docId=档案)`）获取官方身份、阵营与背景；档案是设定，不等于剧情中已揭示的信息。
3. 按章节顺序读首见场景与台词最多的章节：`zzz_read(docId=首见场景)`；本人台词用 `zzz_search(keyword=…, speaker=…)`，被他人提及用 `zzz_search(keyword=名字)`。
4. 每章记一条：处境、动机、与谁互动、发生了什么变化（附 docId + 行号）。
5. 最后串成弧线：初登场印象 → 关键事件 → 关系变化 → 当前状态 / 未解之谜。

## 注意
- 主线是「哲」视角；「铃」作为妹妹出现，涉及她的内容同样按台词记录。
- 不要把同人设定、玩家社区说法当成原文；原文没写的明确标注为推测。
