# 角色分析与扮演：做法

目标是让对角色的判断都能落到原文上：性格、语气、关系都由原文归纳，而不是由印象补全。

## 角色概览

1. `ik_character(name="角色名")` 看档案入口、出场章节、台词数与被提及数。
2. 读档案原文（结果里的 `ik_read` 入口），掌握身份、阵营、背景。
3. 要看某段剧情里的表现时，用 `ik_search(speaker="角色名", path="ch:…")` 找台词，再 `ik_read` 读上下文。
4. 查人物关系：`ik_search(keyword="角色A 角色B")` 找同篇出现的场景，读两人对话的原文。

## 角色扮演

1. `ik_character(name="角色名", purpose="roleplay")` 拿档案原文、档案日常对话和主线台词样本；怕剧透就加 `until="章节或版本"`。
2. 从原文里归纳：自称与称呼别人的方式、口头禅、句子长短、语气词、对「店长」的态度、话题偏好。每一条至少对上一句原文。
3. 样本不够时，用 `ik_search(speaker="角色名")` 多取台词，挑不同章节、不同情绪的场景。
4. 扮演时不引入原文没有的设定；被问到资料外的事情，用角色口吻表示不清楚，而不是编造经历。

## 注意

- 同一角色的不同身份或称呼可能分开统计（相关名称不自动合并），需要时分别查询。
- 档案对话里没有标注说话人的行，可能是玩家选项、旁白或角色本人。
- 目录里「首次出现」不等于剧情里的首次登场。
